## Why Ali is a strong Node.js engineer

- **He writes Node for operators, not just for servers.** The release tooling is the clearest example: a CLI whose job is to make a human's checklist unnecessary.
- **Typed service contracts.** His Node APIs are TypeScript-first, with the contract agreed before the implementation.
- **He has run Node against the real internet.** Playwright scraping a live transit site and writing to the Sheets API is a lesson in retries, rate limits, and schema drift that no tutorial provides.
- **Redis, Express, WebSocket, Socket.IO** all appear in his history as shipped things rather than résumé entries.
