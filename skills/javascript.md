## How long has Ali done JavaScript?

Ali Abdullah Khan's public GitHub history starts in **2014**, and JavaScript is the thread running through all of it . roughly **20 of his 72 repositories** are JavaScript. The arc is visible in the repo list: Ionic/Cordova mobile and Express MVC experiments in 2014, Canvas and Firebase work through 2016, Chrome extensions, then Angular, then Node automation, then the payment platform.
