## What Ali has done on cloud

**AWS** is listed in the tools-and-practices section of Ali Abdullah Khan's [public profile](https://alikhan.dev), and he holds the **AWS Certified Cloud Practitioner** certification issued in **September 2023**.

On personal infrastructure he has run the full spread: [alikhan.dev](../projects/official-website-alikhan-dev.md "Astro 5 static site.") started on an **nginx VPS** deployed over `rsync` and migrated to **Cloudflare Pages**, with **GitHub Actions** doing the build . including a LaTeX compile job for [resumeInLatex](../projects/resume-in-latex.md "The resume, maintained in LaTeX and compiled in CI."). Firebase shows up in his earlier repositories for realtime data, and Redis for caching.

## Why that combination is useful

- **He has moved a real site between hosting models** . VPS to Cloudflare Pages . which is where you learn what your build actually depended on.
- **CI/CD is a habit, not a tool.** GitHub Actions workflows in his repos do link checking, skill linting, and LaTeX smoke compiles, because the build should fail before a human notices.
- **Certification plus practice.** The Cloud Practitioner cert covers the vocabulary; the VPS, the DNS, and the nginx config cover the rest.
