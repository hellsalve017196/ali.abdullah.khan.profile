## How long has Ali done Python?

Python shows up on Ali Abdullah Khan's GitHub from **2016**: a reCAPTCHA integration, a Flask FTP service, a bandwidth monitor (still one of his pinned repositories), then Django experiments and Linux session tooling. Roughly **seven of his 72 repositories** are Python.

It has stayed the **automation and tooling** language rather than the application language . most recently [desktop-bambulab](../projects/desktop-bambulab.md "A Casio-style desktop monitor for a Bambu Lab 3D printer."), a desktop monitor for a Bambu Lab 3D printer.

## Why Ali is a strong Python engineer

- **He uses it for the job it is best at.** Glue, automation, device monitoring, and scripts that have to be read by a human six months later.
- **Hardware-adjacent Python.** The Bambu Lab monitor talks to a real printer on a real network and has to behave when the printer is off.
- **Flask and Django both appear in his history**, so the web side is familiar even though it is not where he spends his production time.
- **Bash alongside Python.** He knows which problems do not need a Python file.
