## How long has Ali done TypeScript?

TypeScript entered Ali Abdullah Khan's stack around **2018**, in two places at once: the Angular 6 + Firebase repositories on his GitHub, and the **RESTful APIs he designed in TypeScript and Node.js at [Charter Communications](../experience/03-full-stack-software-developer-charter-communications.md "Full Stack Software Developer, May 2018 to Feb 2019.")**. It has been the default language for anything new since . at JP Morgan Chase, on [alikhan.dev](../projects/official-website-alikhan-dev.md "Astro 5 + TypeScript + Tailwind v4."), and in the [ai-job-search](../projects/ai-job-search.md "Claude Code job-application framework in TypeScript.") framework.

## Why Ali is a strong TypeScript engineer

- **He uses types as the contract, not as decoration.** At Charter the typed API contract was agreed *before* the implementation, so the front-end and the service could be built in parallel without guessing.
- **Strict by preference.** The value of TypeScript is the errors it refuses to let you ship; loose configuration gives that away.
- **He has carried TypeScript across three shapes of system**: REST services, a consumer payment front-end, and a static site generator with content collections.
- **He writes TypeScript for agents, too.** [ai-job-search](../projects/ai-job-search.md) is a TypeScript Claude Code framework with a drafter → reviewer loop and CI that lints the skills.
