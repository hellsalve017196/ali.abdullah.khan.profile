## How long has Ali done Angular?

Ali Abdullah Khan **modernized legacy systems with AngularJS** at [Charter Communications](../experience/03-full-stack-software-developer-charter-communications.md "Full Stack Software Developer, May 2018 to Feb 2019.") between May 2018 and February 2019. Alongside it, his GitHub from the same period carries the Angular 6+ TypeScript trail: `Angular_firebase_CRUD`, `angular-boilerplate`, `get_post_in_angular6`.

It is listed on his [public profile](https://alikhan.dev) as a framework he works in, and it is the reason TypeScript became his default language.

## Why that experience still matters

- **Legacy modernization is the transferable skill**, not the framework. The Charter work was strangler-style: new screens in AngularJS, old screens untouched until replaced, nothing taken offline for the migration.
- **He has lived through a framework generation change.** AngularJS → Angular → React is not a résumé line; it is a set of opinions about why component boundaries matter.
- **Dependency injection and service boundaries** from the Angular world carry directly into how he structures front-end state today . see [React review notes](react.md#review-notes).
