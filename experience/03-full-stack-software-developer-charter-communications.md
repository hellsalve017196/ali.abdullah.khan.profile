## TL;DR

The role before the bank, and the one that set the pattern: **take something legacy and make it maintainable.** Ali Abdullah Khan modernized legacy systems with **AngularJS** and designed **RESTful APIs in TypeScript and Node.js** for internal products. This is where TypeScript stopped being a preference and became the default.

## Responsibilities and Achievements

💡 **Modernized legacy systems with AngularJS** . incremental migration rather than a rewrite, because the systems were in use the whole time.

💡 **Designed RESTful APIs in TypeScript and Node.js** for internal products, with the contract agreed before the implementation.

💡 Worked across the stack . front-end, API, and the integration seam between them, which is where most of the bugs were.

💡 Built the habit that carried into JP Morgan Chase: **the interface is the deliverable**. A clear API contract removes a whole category of coordination cost.

## Projects

### `Legacy system modernization (AngularJS)`

Internal tooling that predated modern front-end practice. The approach was strangler-style: new screens in AngularJS, old screens untouched until replaced, nothing taken offline for the migration.

### `Internal REST API layer (TypeScript + Node.js)`

REST services in TypeScript and Node.js behind internal products. Typed contracts up front, so the front-end and the service could be built in parallel without guessing.
