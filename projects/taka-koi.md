# taka_koi . A Household Expense Tracker, Still at Spec

> **TL;DR** . A household expense tracker that is deliberately **not implemented yet**. The repository contains a PRD, `product_requirement.md`, `screen_for_app.md`, and a `design_discussion.pen` design file . and no application code. That is the interesting part.

**Repo:** [taka_koi](https://github.com/hellsalve017196/taka_koi "Household expense tracker at the specification stage . PRD, screens, and design discussion before code.") · Sep 2026

### [← Back](../README.md) . [Profile](../ali-abdullah-khan-profile.md)

## Why it is still a spec

Because starting with the code is how you end up with an expense tracker that technically works and that nobody in the household will use.

The name is Bengali . *taka koi?*, roughly **"where's the money?"** . which is also the product requirement.

## What is in the repository

| File | What it holds |
|---|---|
| `prd.md` / `product_requirement.md` | What the thing is for, and what it is not for |
| `screen_for_app.md` | The screens, enumerated before they are built |
| `design_discussion.pen` | The visual design file |

## Why this shows up on a profile

It is the clearest example of Ali Abdullah Khan's current working pattern: **spec first, agents second, code third.** The same `prd.md`-before-`src/` ordering appears in the [adhan clock](adhan-clock-esp32-a1s.md "prd.md, AGENTS.md, CLAUDE.md, then per-subsystem test sketches.") and in [ai-job-search](ai-job-search.md "A drafter and a separate reviewer agent."), and it is the personal-project version of the [AI-driven SDLC](../systems/ai-driven-sdlc.md "Humans review the PRD, not the diff.") he built at work.

A repository with a PRD and no code is not an abandoned project. It is a project that has not yet earned its code.
